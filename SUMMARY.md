## 📦 ОСНОВНЫЕ ФАЙЛЫ (3 шт) - КОПИРУЙ В СВОЙ ПРОЕКТ

### 1. **cdek_integration.py** (⭐ ГЛАВНЫЙ)
- **Размер:** ~400 строк
- **Что делает:** Модуль с функциями для работы с CDEK API v2.0
- **Главные функции:**
  - `calculate_shipping(city_name)` → (cost, description)
  - `get_cdek_oauth_token()` → token
  - `validate_phone(phone)` → bool
  - `validate_city(city_name)` → bool

**Особенности:**
- ✅ Асинхронность (async/await)
- ✅ Кэширование OAuth токена (55 минут)
- ✅ Обработка 10+ типов ошибок
- ✅ Дефолт стоимость 500 ₽ при любой ошибке
- ✅ Полное логирование

**Использование:**
```python
from cdek_integration import calculate_shipping
cost, desc = await calculate_shipping("Москва")
```

---

### 2. **bot_with_cdek.py** (⭐ ГОТОВ К ЗАПУСКУ)
- **Размер:** ~300 строк
- **Что делает:** Полный бот на aiogram 3.x + FastAPI API сервер
- **Структура:**
  ```
  AIOGRAM:
  ├── /start handler → показывает кнопку Mini App
  ├── web_app_data handler → получает заказы из Mini App
  ├── format_customer_confirmation() → сообщение покупателю
  └── format_admin_notification() → уведомление админам
  
  FastAPI:
  ├── POST /api/calculate-shipping → расчет доставки
  ├── GET /api/health → проверка статуса
  └── GET / → информация об API
  ```

**Запуск:**
```bash
python bot_with_cdek.py
# Результат:
# ✅ API запущена на http://127.0.0.1:8000
# 🤖 Запускаю Telegram бота...
```
